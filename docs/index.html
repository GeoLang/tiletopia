Features

🧊 Tiling Engine

  • OGC 3D Tiles 1.1 output
  • Octree spatial partitioning with LOD
  • Parallel tiling (Rayon work-stealing)
  • GPU-accelerated via wgpu (Metal/Vulkan)
  • Incremental/diff-based tiling
  • Draco/meshopt compression

📂 Input Formats

  • LAS, LAZ, E57, PLY (point clouds)
  • glTF, GLB, OBJ, FBX, IFC (3D models)
  • GeoTIFF, DTED, HGT (terrain DEMs)
  • GeoJSON, Shapefile, KML (vector)
  • CityGML, CityJSON (urban models)

🌐 Tile Server

  • REST API for asset management

  • WebSocket real-time data layer
  • JWT authentication (on by default)

🤖 AI Agent — Natural Language Viewer Control

Control the 3D viewer through conversation. No GIS expertise required.

Viewer Commands

CommandAction
fly_toAnimate camera to coordinates
classifyApply ASPRS classification colors
add_geojsonOverlay GeoJSON layer
load_tilesetLoad 3D Tiles dataset
add_markerPlace labeled pins
screenshotCapture current view

Powered by sibyl, a Rust agent loop that calls an OpenAI-compatible LLM endpoint and keeps sessions in sqlite. It dispatches tool calls over HTTP to the GeoLang API, which runs 36 geospatial tools in-process (geocoding, isochrones, clustering, terrain profiles, environmental risk, routing). Sessions do not share memory, each one starts clean.

Quick Start

# Build from source
git clone https://github.com/GeoLang/tiletopia.git
cd tiletopia && cargo build --release

# Tile a point cloud
tiletopia tile --input scan.las --output ./tileset

# Start server
tiletopia serve --data-dir ./data --port 3000

# Docker
docker run -p 3000:3000 -v ./data:/data tiletopia serve --data-dir /data
