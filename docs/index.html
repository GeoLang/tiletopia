🌍 tiletopia

Fast open-source 3D Tiles server — self-hosted Cesium Ion replacement for digital twins and geospatial visualization.

GitHub Quick Start

Features

Tiling Engine

  • OGC 3D Tiles 1.1 output
  • Octree spatial partitioning with LOD
  • Parallel tiling (Rayon work-stealing)
  • GPU-accelerated via wgpu (Metal/Vulkan)
  • Incremental tiling & resume
  • Draco/meshopt compression

Input Formats

  • LAS, LAZ, E57, PLY (point clouds)
  • glTF, GLB, OBJ, FBX, IFC (3D models)
  • GeoTIFF, DTED, HGT (terrain)
  • GeoJSON, Shapefile, KML (vector)
  • GeoTIFF, JPEG2000 (imagery)

Tile Server

  • REST API for asset management
  • View-dependent tile streaming
  • WebSocket real-time data layer
  • CORS support for CesiumJS
  • Prometheus metrics endpoint

Digital Twin

  • Real-time IoT/sensor data injection
  • Temporal versioning (time-series)
  • Entity linking (3D → metadata)
  • Live model update API

Storage

  • Local filesystem (zero-config)
  • S3 / GCS / Azure Blob backends
  • Hybrid hot/cold storage

Deployment

  • CLI tool for local tiling
  • Docker image
  • Web dashboard with CesiumJS preview
  • Linux, macOS, Windows

Architecture

tiletopia/
├── crates/
│   ├── tiletopia-core/       # Tiling engine, spatial indexing, LOD, 3D Tiles types
│   ├── tiletopia-server/     # Axum REST API, tile streaming, WebSocket
│   ├── tiletopia-worker/     # Async tiling pipeline, job queue
│   ├── tiletopia-ingest/     # Format readers (LAS, CityGML, GeoTIFF, glTF)
│   ├── tiletopia-terrain/    # Quantized mesh terrain generation
│   ├── tiletopia-store/      # Storage abstraction (local, S3, GCS, Azure)
│   └── tiletopia-cli/        # CLI binary
├── gui/                      # Web dashboard (Vite + CesiumJS preview)
└── docs/                     # Documentation
