GeoLang Ecosystem

A modular geospatial platform, AGPL-3.0. The 22 repositories below are Rust apart from viewtopia, which is TypeScript, and terravista, whose Android view is Kotlin. The platform holds more than these, and its LLM tool API is Python.

Platform

tiletopia

Self-hosted 3D Tiles server for point clouds, meshes, IFC and terrain

server

viewtopia

Web viewer with a Cesium globe, MapLibre and Leaflet maps, and a chat agent that drives the map

frontend

ptolemy

Versioned geodatabase on PostgreSQL and PostGIS with branches, diffs and merges

server

fenestra

OGC services gateway with WMS, WFS, WMTS, WCS, OGC API Features and MVT tiles

server

sibyl

LLM agent loop service that calls an OpenAI-compatible endpoint and sends tool calls to an HTTP executor

server

agora

Live multiplayer session service that stores composition documents and sends each edit to everyone who has the document open

server

collecta

Field data collection server and form library, with ODK Collect over OpenRosa and an offline command line client

server

Routing & Navigation

itinera

Routing engine for OpenStreetMap road networks with isochrones and map matching over HTTP

server

geokode

Self-hosted geocoding service

server

interiora

Indoor mapping and navigation library and HTTP server

server

Spatial Analysis

terrano

Raster algebra and terrain analysis engine

library

nubis

Point cloud processing engine

library

panoptes

Library and CLI that segments aerial and satellite imagery into GeoJSON polygons

library

geoplumb

Pull-based geospatial compute pipeline that computes only the requested window, with an XYZ tile server

server

Streaming

library

Geometry & Topology

topoi

Computational geometry engine

library

library

Data & Visualization

Version control for geospatial data on top of Git

library

Symbology and cartographic rendering engine

verne

Reads KML, Esri file geodatabases and ArcGIS services, reports what GeoLang can hold exactly, and loads them into ptolemy

cli
